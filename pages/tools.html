CV

Kalkulator konverter

Konversi satuan yang sering dipakai untuk perhitungan struktur, geoteknik, hidrologi, dan RAB.

Hasil1 m = 100 cm

Pilih kategori satuan, masukkan angka, lalu tekan hitung.

KC

KML/KMZ to CSV Civil 3D

Konversi hasil export Google Earth menjadi CSV comma delimited berisi LAT, LONG, ALT tanpa judul, siap dipakai sebagai point file Civil 3D.

Format output

Pilih PLLA untuk latitude/longitude, atau PENZ/PNEZ untuk koordinat UTM WGS84 otomatis dari titik Google Earth.

1,-7.665294,110.595746,229.331
RS

Response spectrum ETABS

Masukkan parameter dari RSA/Web RSA, hitung tabel dan grafik, lalu download TXT siap import ke SAP/ETABS atau grafik PNG secara terpisah.

Ringkasan spektrum

Isi Ss, S1, TL, dan kelas situs. Klik Hitung Spektrum untuk menampilkan tabel data dan grafik respons spektrum.

SDS: -SD1: -T0: -Ts: -
EP

Export PDF

Buat PDF sederhana dari catatan, ringkasan tugas, atau dokumentasi singkat tanpa aplikasi tambahan.

Format output

PDF memakai ukuran A4, margin rapi, tanggal otomatis, dan identitas dokumen di bagian bawah.

Cocok untuk catatan singkat, rangkuman, memo kegiatan, dan draft laporan sederhana.

PM

PDF merger

Gabungkan beberapa PDF menjadi satu file. Pilih banyak file sekaligus, lalu cek daftar dan atur dengan tombol Naik/Turun jika browser mengurutkan otomatis.

Belum ada PDF dipilih.

Privasi file

File PDF diproses lokal di browser. Tidak ada upload ke browser lokal.

Untuk file besar, proses bisa membutuhkan beberapa detik tergantung perangkat.

PI

PDF to image

Ubah halaman PDF menjadi gambar PNG untuk kebutuhan preview, dokumentasi, atau lampiran chat.

Preview gambar akan muncul di sini.

JP

JPG to PDF

Gabungkan satu atau beberapa gambar JPG/JPEG menjadi file PDF A4. Gambar otomatis menyesuaikan halaman tanpa terpotong.

Belum ada gambar dipilih.

Cara kerja

Setiap gambar menjadi satu halaman PDF. File diproses langsung di browser, jadi gambar tidak diupload ke server.

Untuk hasil rapi, gunakan gambar dengan resolusi cukup besar dan nama file berurutan.
